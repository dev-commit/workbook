# v-once

::: tip `v-once`

- **v-once** - отрисовка элемента и компонента выполняется только один раз, а последующие обновления пропускаются
- При последующих повторных отрисовках этот элемент/компонент и все его дочерние элементы будут рассматриваться как статическое содержимое и пропускаться. Это может быть использовано для оптимизации производительности при обновлении
  :::

```vue
<script setup>
import { ref } from "vue";

const message = ref("Первое сообщение");
</script>

<template>
  <!-- При клике на кнопку останется "Первое сообщение" -->
  <p v-once>Это никогда не изменится: {{ message }}</p>

  <!-- При клике на кнопку отобразится "Новое сообщение" -->
  <p>{{ message }}</p>
  <button @click="message = 'Новое сообщение'">Click</button>
</template>
```
