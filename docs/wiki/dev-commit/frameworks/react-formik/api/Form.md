# `<Form />`

::: info
https://formik.org/docs/api/form
:::

Обёртка для формы.

```js
import { Formik, Form } from "formik";

const App = () => {
  return (
    <Formik>
      <Form>
        ⚡️ Поля для обработки
        <button type="submit">Submit</button>
      </Form>
    </Formik>
  );
};
```
