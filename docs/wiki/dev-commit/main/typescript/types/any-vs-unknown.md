# Any vs Unknown

### Unknown можно переопределить

- unknown можно определить потом через as

```js
const a: any;
const b: unknown;

a.b = 1; // Можно добавить ключи
b.a = 2  // Нельзя добавить ключи

(param as Custom).something
```

### unknown - безопаснее чем any

- При указани через any есть риск обратиться к методу неверного типа. Н-р, предполагали, что будет string и обратились к методу length, что вызвало ошибку, т.к. там был объект.
- unknown не даст сделать подобного - он будет выдавать предупреждение
