# Наследование в Дженериках

- При вызове функции можно явно не указывать Дженерик: foo&lt;IBasic&gt;
- Дженерик подставится автоматически в зависимости от аргументов
- В данном случае, обязательным является только { name: string }, т.к. указан в IBasic

```js
interface IBasic {
    name: string;
}

const foo = <T extends IBasic>(data: T): void => {
    //
}

foo({
    // Только это поле обязательное
    name: 'Tom',
    // Остальные поля могут быть любые
    age: 22,
});
```
