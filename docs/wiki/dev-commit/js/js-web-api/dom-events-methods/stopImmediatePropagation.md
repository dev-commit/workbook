# stopImmediatePropagation

        Предотвращает дальнейшее распространение текущего события на фазах погружения и всплытия, при этом происходит остановка на текущем элементе: предотвращает распространение на другие обработчики событий текущего элемента
    
- Если к одному и тому же элементу для одного и того же типа события прикреплено несколько слушателей, они вызываются в том порядке, в котором были добавлены. Если во время одного такого вызова вызывается stopImmediatePropagation(), остальные слушатели не будут вызываться ни для этого элемента, ни для любого другого элемента
