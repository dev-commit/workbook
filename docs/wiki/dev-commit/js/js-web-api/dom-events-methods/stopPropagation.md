# stopPropagation

## Информация

::: danger

**`event.stopPropagation()`** - предотвращает дальнейшее распространение текущего события на фазах _погружения_ и _всплытия_

:::

- Не предотвращает появление поведения по умолчанию; например, клики по ссылкам все еще обрабатываются (для этого нужен _preventDefault()_)
- Не предотвращает распространение на другие обработчики событий текущего элемента (для этого нужен _stopImmediatePropagation_)
