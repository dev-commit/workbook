# requestAnimationFrame

## Информация

::: danger

**`window.requestAnimationFrame(callback, element)`** - указывает браузеру на то, что вы хотите произвести анимацию, и просит его запланировать перерисовку на следующем кадре анимации. В качестве параметра метод получает функцию, которая будет вызвана перед перерисовкой.

> - `callback` - функция, которая будет вызвана, когда придёт время обновить вашу анимацию на следующей перерисовке
> - `element` - (необязательный) - (не используется в Firefox или IE), определяющий элемент, который визуально содержит всю анимацию. Для canvas'а и WebGL'a им должен быть Canvas. Для других элементов вы можете опустить этот параметр для чуть лучшего пользовательского опыта
> - _return_ - requestID - длинное целое, являющееся уникальным идентификатором для записи, содержащей callback. Оно не равно нулю, но других предположений о его значении делать не следует. Вы можете передать его в window.cancelAnimationFrame() для отмены вызова

:::

::: tip

- **requestAnimationFrame** - соответствует обновлением экрана экрана. Анимация элементов DOM. Передаем callback, который нужно вызвать перед рендером

:::

- **Примечание**: Ваш callback метод сам должен вызвать requestAnimationFrame() иначе анимация остановится.
- Вы должны вызывать этот метод всякий раз, когда готовы обновить анимацию на экране, чтобы запросить планирование анимации. Обычно запросы происходят 60 раз в секунду, но чаще всего совпадают с частотой обновления экрана. Большинство дисплеев обновляются с частотой 60Гц.

## Пример

**Использование requestAnimationFrame**

```js
let step = 1;

const animate = () => {
  const element = document.getElementById("element");
  element.style.transform = `translateX(${step++}px)`;
  // callback явно вызывает requestAnimationFrame
  window.requestAnimationFrame(animate);
};

window.requestAnimationFrame(animate);
```

**Стандартное поведение**

```js
// до рендеринга дойдёт только последний
button.addEventListener("click", () => {
  box.style.display = "none";
  box.style.display = "block";
  box.style.display = "none";
});
```
