# Tree shaking

## Информация

::: tip

- **Tree shaking** (встряхивание дерева) - метод оптимизации библиотек путем удаления любого кода из окончательного файла, который фактически не используется.
  :::

- Когда приложение на Javascript достигает определенного размера, его обычно разделяют на модули. Однако, через какое то время, становиться сложно отслеживать все что импортируется и как это используется. В итоге при сборке пакетов, мы можем получить большое количество импортированный кода, который фактически не используется.
- Если воспользоватьчя tree shaking, тогда только то, что мы импортировали и фактически использовали попадет в окончательную сборку.
- Tree shaking может работать только в том случае, если модули являются статическими («static»)

## Примеры

```js
// Импорт, который импортируется, но не используется, впоследствии полностью исключается
import { add, multiply } from "math";
add(1, 2);
```

## Настройка Tree shaking в Webpack

::: code-group

```js [webpack.config.js]
module.exports = {
  mode: "production",
};
```

```js [package.json]
// Пометить определенные файлы как исключения для Tree shaking
{
	"sideEffects": [
		"./src/polyfill.js"
	]
}
```

:::
