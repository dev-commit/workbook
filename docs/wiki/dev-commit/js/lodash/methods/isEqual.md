# isEqual

::: tip isEqual

- **isEqual** - сравнение объектов
  :::

## Установка

```bash
npm i --save lodash # Установка всего lodash
npm i --save lodash.isequal # Установка только lodash.isequal
```

## Использование

```js
import isEqual from "lodash.isequal";

const obj1 = { a: 1 };
const obj2 = { a: 1 };
const res = isEqual(obj1, obj2); // => true
```
