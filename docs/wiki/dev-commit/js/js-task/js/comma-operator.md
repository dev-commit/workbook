# Оператор "запятая"

<!-- prettier-ignore -->
```js
console.log([0,1][0,1])
```

- console.log выводит то, что вернёт выражение
- Оператор "запятая": выполни все, что есть до запятой, и верни последнее значение
- Вторые скобки - не массив, а обращение по индексу: `0,1` вернёт 1, и нам вернется элемент первого массива с индексом 1 - это 1
- Он выполняет все выражения, но возвращает только последнее значение
