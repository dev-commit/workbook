# Series

::: warning

- Проверить код

:::

## Информация

- _Задача_: реализовать функцию `series`, которая принимает:
  1. массив функций - у каждой функции интерфейс `(аргумент, колбэк)`
  2. начальное значение
  3. финальный колбэк
- Функции вызываются по очереди: каждая получает результат предыдущей и асинхронно отдаёт новый результат через колбэк. Финальный колбэк получает результат последней функции

```js
function foo(x, cb) {
  setTimeout(() => cb(x + 1), 10);
}

function bar(x, cb) {
  setTimeout(() => cb(x * 3), 10);
}

series([foo, bar], 4, (result) => {
  console.log(result); // 15 = (4 + 1) * 3
});
```

## Решение

```js
async function series(fns, initialValue, callback) {
  let value = initialValue;

  for (const fn of fns) {
    // Промисификация: ждём, пока функция вызовет свой колбэк
    value = await new Promise((resolve) => fn(value, resolve));
  }

  callback(value);
}
```

- `await` внутри цикла: следующая функция запускается только после того, как предыдущая вызвала свой колбэк
- Пустой массив функций - финальный колбэк получит начальное значение
