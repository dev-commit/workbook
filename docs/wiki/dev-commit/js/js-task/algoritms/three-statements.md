# 3 утверждения

::: warning

- Проверить код

:::

## Задача

Даны 3 утверждения:

1. В коде больше 10 багов
2. В коде меньше 10 багов
3. В коде наверняка есть один баг

Если истинно только одно утверждение - сколько багов в коде?

## Ответ

**Ответ: 0 багов.**

Ниже перебор вариантов. Пусть N — число багов.

| N   | 1. «больше 10» | 2. «меньше 10» | 3. «есть один баг»           | Сколько истинных |
| --- | -------------- | -------------- | ---------------------------- | ---------------- |
| 0   | ложь           | **истина**     | ложь                         | **1** ✅         |
| 1   | ложь           | истина         | истина                       | 2 ❌             |
| 2–9 | ложь           | истина         | ложь (если «ровно один»)     | 1 ✅ ⚠️          |
| 10  | ложь           | ложь           | ложь / истина                | 0 или 1          |
| >10 | истина         | ложь           | истина (если «хотя бы один») | 2 ❌             |

Ответ зависит от того, как понимать третье утверждение.

**Если «есть один баг» значит «хотя бы один»** (так обычно и понимают «наверняка есть баг»):

- Утверждения 1 и 2 не могут быть истинными одновременно. При N ≠ 10 одно из них истинно, значит третье должно быть ложным, то есть N = 0. Проверяем: 0 < 10 — истина, остальные ложны ✅
- Особый случай N = 10: первые два ложны, третье истинно. Это тоже ровно одно истинное утверждение ✅

**Если «есть один баг» значит «ровно один»:**

- N = 0 подходит: истинно только второе утверждение.
- Но подходят и N от 2 до 9: истинно только второе, а третье ложно.
- N = 10 не подходит: все три утверждения ложны.

Только N = 0 подходит при любом прочтении, поэтому это и есть задуманный ответ: **в коде нет багов**. Подвох в том, что фраза «наверняка есть баг» оказывается ложью.

Если строго понимать третье утверждение как «хотя бы один баг», то 10 тоже даёт ровно одно истинное утверждение.
