# Количество повторяющихся элементов

::: warning

- Проверить код

:::

## Задание

- Есть массив с числами
- Нужно найти число, которое повторяется максимальное количество раз

```js
const arr = [1, 2, 4, 1, 2, 2, 4];
```

## Реализация

```js
const arr = [1, 2, 4, 1, 2, 2, 4];

const mostFrequent = (arr) => {
  // Map хранит ключи в порядке добавления и не превращает их в строки
  const counts = new Map();

  // Подсчитываем количество повторений
  for (const num of arr) {
    counts.set(num, (counts.get(num) || 0) + 1);
  }

  // Находим число с максимальным количеством повторений.
  // При ничьей остаётся число, которое встретилось в массиве первым
  let maxNum = null;
  let maxCount = 0;

  for (const [num, count] of counts) {
    if (count > maxCount) {
      maxCount = count;
      maxNum = num;
    }
  }

  return maxNum;
};

console.log(mostFrequent(arr)); // 👉 2
console.log(mostFrequent([3, 3, 1, 1])); // 👉 3
```

### Объяснение

1. Создаётся `Map` counts, где ключ — число, значение — сколько раз оно встретилось
2. После прохода по массиву ищем ключ с максимальным значением
3. Возвращаем это число. При ничьей - то, что встретилось в массиве первым: `Map` перебирает ключи в порядке добавления. У обычного объекта целые ключи перебираются по возрастанию, и при ничьей вернулось бы меньшее число
