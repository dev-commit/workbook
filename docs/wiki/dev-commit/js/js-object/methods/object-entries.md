# Object.entries()

## Информация

::: tip Определение

- **Object.entries()** - метод возвращает массив собственных перечисляемых свойств указанного объекта в формате `[key, value]`, в том же порядке, что и в цикле `for...in` (разница в том, что for-in перечисляет свойства из цепочки прототипов). Сначала идут целочисленные ключи по возрастанию, затем остальные строковые ключи в порядке добавления. Если нужен определённый порядок, полученный массив сортируют, например `Object.entries(obj).sort((a, b) => a[0] - b[0])`

:::

```js
const obj = {
  foo: "bar",
  baz: 42,
};

console.log(Object.entries(obj)); // [ ['foo', 'bar'], ['baz', 42] ]
```
