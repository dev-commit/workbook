# Object.assign

## Информация

::: danger

**`Object.assign(target, ...sources)`** - копирование значений всех собственных перечисляемых свойств (при обходе в цикле for..in его можно будет получить) из одного или более исходных объектов в целевой объект. Происходит создание поверхностной копии

> - `target` - целевой объект
> - `sources` - исходные объекты
> - _return_ - получившийся целевой объект

:::

```js
let obj = Object.assign({ name: "Tony" }, { age: 25 });
// obj {name: "Tony", age: 25}
```
