# Object.create

    добавление прототипа при создании объекта (создаёт пустой объект с __proto__, равным первому аргументу, второй содержит дескрипторы свойств)
    
объект, который станет прототипом вновь созданного объекта (__proto__)
дескрипторы свойств. Необязательный параметр. Если указан и не равен undefined, должен быть объектом, чьи собственные перечисляемые свойства (то есть такие, которые определены на самом объекте, а не унаследованы по цепочке прототипов) указывают дескрипторы свойств, добавляемых в новый объект. Имена добавляемых свойств совпадают с именами свойств в этом объекте. Эти свойства соответствуют второму аргументу метода Object.defineProperties()
Новый объект с заданным прототипом и свойствами

```js
const obj = Object.create(
	{ name: 'Tony' }
);
// => {} => __proto__: name: "Tony"
```

## Задачи

```js
var obj = { name: 'Tony' };
var objNew = Object.create(obj);

console.log(objNew.name); // "Tony"
delete objNew.name;
console.log(objNew.name); // "Tony"

delete obj.name;
console.log(objNew.name); // undefined
```

---

```js
// Структура objNew
objNew = {
	_proto_: {
		name: "Tony"
	}
}
```
