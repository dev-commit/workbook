# Логическое преобразование

## Информация

- В **логическом** контексте объект - всегда _true_

## Логическое преобразование

```js
// Любой объект в логическом контексте – true, даже если это пустой массив [] или объект {}.
if ({} && []) {
  console.log("Все объекты - true!"); // console.log сработает
}
```
