# Перебор объекта

## Цикл `for in`

::: danger

**`for (variable in object) {...}`** - проходит через перечисляемые свойства объекта и его цепочку прототипов. Он пройдёт по каждому отдельному элементу. Порядок перебора соответствует порядку объявления для нечисловых ключей, а числовые или числовые строки сортируются

> - `variable` - другое (очередное) имя свойства назначается переменной на каждой итерации
> - `object` - объект, по чьим свойствам мы проходим

:::

```js
for (let key in obj) {
  console.log(key); // Ключи
  console.log(obj[key]); // Значения
}
```

## `Object.keys` и `forEach`

```js
const values = {
  name: "Tony",
  age: 25,
};

Object.keys(values).forEach((key) => {
  const data = values[key];
  console.log(data);
});
```

## Перечисление всех свойств объекта

```js
// Возвращает массив со всеми собственными именами перечисляемых свойств объекта
// (те, что в цепочке прототипов, не войдут в массив)
const a = Object.keys(obj);

// Количество свойств
const a = Object.keys(obj).length;

// Возвращает массив содержащий все имена своих свойств (перечисляемых и неперечисляемых) объекта
const a = Object.getOwnPropertyNames(obj);
```
