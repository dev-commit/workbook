# Проверка наличия свойства

## Информация

- Можно обратиться к любому свойству объекта, даже если его нет. Если свойство не существует, вернется _undefined_

## Пример

- Проверка наличия свойства 'name' в объекте

```js
// Не различает отсутствующие свойства и те что были установлены в undefined
const a = obj.name;

// Различает отсутствующие свойства и те что были установлены в undefined
const a = "name" in obj;

// Не берет наследованные свойства
const a = obj.hasOwnProperty("name");
```
