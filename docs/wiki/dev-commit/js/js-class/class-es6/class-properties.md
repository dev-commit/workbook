# Class Properties - Свойства классов

## Информация

- Не является стандартом, для транспиляции нужен Babel

1. _Инициализация свойств в теле класса_ - когда свойства не зависят от внешних параметров, нет необходимости использовать конструктор
2. _Функции, автоматически привязанные к объекту, который создается_ - вне зависимости от того как будет вызвана функция, _this_ будет тот объект с которым она была создана. Применение: при регистрации функции как _EventListener_

```js
class Counter {
  count = 1;

  inc = () => {
    this.count++;
    console.log(this.count);
  };
}

const cnt = new Counter();
console.log(cnt.count); // => 1
cnt.inc(); // => 2
setTimeout(cnt.inc, 1000); // => 3
```
