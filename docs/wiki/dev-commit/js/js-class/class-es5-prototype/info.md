# Теория

## Информация

::: tip Определение

- **Класс** - _функция-конструктор_ вместе с её _prototype_. Такой способ объявления классов называют _«прототипным стилем»_. При наследовании часть методов переопределяется, например, у массива Array есть свой toString

:::

- _Функциональный стиль_ записывает в каждый объект и свойства и методы, а _прототипный_ – только свойства
- При создании методов через прототип, мы теряем возможность использовать локальные переменные как приватные свойства, у них больше нет общей области видимости с конструктором
