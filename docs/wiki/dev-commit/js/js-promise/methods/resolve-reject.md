# Promise.resolve(value) и Promise.reject(error)

создаёт успешно выполнившийся промис с результатом value. Используют, когда хотят построить асинхронную цепочку, и начальный результат уже есть
результат

создаёт уже выполнившийся промис с ошибкой error. Используется очень редко, т.к. ошибка возникает обычно не в начале цепочки, а в процессе её выполнения
ошибка
#### 

```js
Promise.resolve(55)
	.then(val => console.log(val))
```

#### 

```js
Promise.reject(new Error("..."))
	.catch(val => console.log(val))
```
