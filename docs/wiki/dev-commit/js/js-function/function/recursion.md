# Рекурсия

## Информация

### Отличие рекурсии от цикла

- Рекурсия будет висеть в памяти. Цикл на каждой итерации новый

## Примеры

### Степень pow(x, n) через рекурсию

```js
function pow(x, n) {
	// пока n != 1, сводить вычисление pow(x,n) к pow(x,n-1)
	if (n != 1) {
		return x * pow(x, n - 1);
	} else {
		return x;
	}
}
alert( pow(2, 3) ); // 8
```
