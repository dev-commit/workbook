# split()

## Информация

::: tip

- **arr.join()** - обратное преобразование
  :::

## Примеры

### Базовое использование

```js
// Преобразование строки с заданным разделителем в массив
const arr = str.split(";");
```

### RegExp

```js
const pattern = /[\s,]+/;
const result = text.split(pattern); // Разделитель - пробелы и запятые
```
