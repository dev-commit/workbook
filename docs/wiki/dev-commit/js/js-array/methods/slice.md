# slice(), splice()

## slice

```js
// Копировать с 1 до 7 не включая, если не указан второй аргумент, то до конца
const arr2 = arr1.slice(1, 7)

// Копировать с 1 до конца
const arr2 = arr1.slice(1)

// Копировать c 2 элемента с конца и дальше
const arr2 = arr.slice(-2)

// Копировать весь массив
const arr2 = arr.slice();
```

## splice

```js
// Удалить с 3 индекса 2 элемента
arr.splice(3, 2)

// Добавление элементов
arr.splice(2, 0, 'Алина', 'Марина')

// Замена элементов (заменить 2 удаленных элемента на Алексей, Билл)
arr.splice(1, 2, 'Алексей", "Билл')

// Удалить с последнего индекса-1 1 элемент (отрицательная позиция отсчитывается с конца)
arr.splice(-1, 1);
```
