# indexOf() / lastIndexOf()

## `indexOf()`

::: tip

- **indexOf** - возвращает первый индекс, по которому элемент может быть найден в массиве или -1, если индекса нет
  :::

```js
const a = colors.indexOf("white");
```

## `lastIndexOf()`

::: tip

- **lastIndexOf** - возвращает последний индекс, по которому данный элемент может быть найден в массиве или -1, если такого индекса нет
  :::

```js
const a = colors.lastIndexOf("white");
```
