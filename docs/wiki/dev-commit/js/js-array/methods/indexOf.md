# indexOf() / lastIndexOf()

```js
// возвращает первый индекс, по которому элемент может быть найден в массиве
// или -1, если индекса нет
const a = colors.indexOf('white');
```

```js
// возвращает последний индекс, по которому данный элемент может быть найден в массиве
// или -1, если такого индекса нет 
const a = colors.lastIndexOf('white');
```
