# forEach()

## Информация

::: danger

**`arr.forEach(callback, thisArg)`** - выполняет указанную функцию один раз для каждого элемента в массиве

> - `callback` - функция, которая будет вызвана для каждого элемента массива; в нее будет передано три аргумента:
>   - `currentValue` - текущий обрабатываемый элемент массива
>   - `index` - индекс текущего обрабатываемого элемента в массиве
>   - `array` - массив, по которому осуществляется проход
> - `thisArg` - необязательный параметр. Значение, используемое в качестве this при вызове функции callback

:::

```js
arr.forEach((currentValue, index, array) => {
  // Your iterator
}[, thisArg]);
```

- Ничего не возвращает, используется только для перебора

```js
const arr = ["Яблоко", "Апельсин", "Груша"];
arr.forEach((element, index, arr) => {
  console.log(element, index, arr);
});
// 'Яблоко'   0  Array(3)
// 'Апельсин' 1  Array(3)
// 'Груша'    2  Array(3)
```
