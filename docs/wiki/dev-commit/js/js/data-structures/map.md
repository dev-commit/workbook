# Коллекции Map и WeakMap (ES6)

## Информация

::: tip Определение

- **Map и WeakMap** - позволяют хранить пары "ключ:значение"
- **Map** - создаёт новый массив с результатом вызова указанной функции для каждого элемента массива

:::

- Отличие от объекта: ключ map может быть любого типа, а не только строки и символы как у объекта

**Информация**

- Используется для трансформации массива
- Объект map, ассоциативный массив
- Нет литеральной формы, поэтому используется конструктор new
- Объект map в отличие от обычного объекта является перебираемым объектом, который можно перебирать в цикле for...of
- Можно использовать деструктуризацию, spread-операторы, Array.from и т.д. присущие итерируемому объекту
- Сохраняет первоначальный порядок элементов, в отличие от объекта

**Map удобнее объекта**

- Если ключи являются динамическими, т.е. известны на этапе выполнения
- Если ключи могут быть разных типов
- Если пары "ключ:значение" часто добавляются/удаляются
- Если пары "ключ:значение" нужно перебирать

**Отличия WeakMap от Map**

- Ключом может быть только объект
- Нет метода clear()
- Нет свойства size
- Не является итерируемым
- Если удаляется объект-ключ, то данные с этим ключом также удаляются из памяти

**Варианты использования WeakMap**

- Кэширование вычисляемых значений. Если нужно значение на основе полей объекта, сохраняем его в WeakMap, а ключом делаем сам объект и когда оно повторно понадобится - берем из кэша. Если значение удаляется, память освободится автоматически
- Управление обработчиками событий. Обработчики событий для объекта сохраняются в WeakMap, а ключом является сам объект. Если объект удаляется, то и обработчики для него удаляются автоматически
- Хранение приватных данных. Приватные данные для объекта сохраняются в WeakMap, а ключом является объект

## Варианты

### Задание значений при объявлении

```js
const map = new Map([
  ["Hi", "Привет"],
  [42, "Ответ на главный вопрос"],
  [true, false],
  [{}, "Объект"],
  [function () {}, "Функция"],
  [null, 1],
  [undefined, 2],
  [NaN, 3],
]);
```

### Перебор map

```js
for (let [key, value] of map) {
  console.log(key, value);
}

map.forEach((value, key, map) => console.log(value, key));
```

## Методы

::: details `set()` - установить значение

```js
const map = new Map();
// Установить значение
map.set(42, "Ответ на главный вопрос");
```

```js
const map = new Map();
map
  .set("HTML", "HyperText Markup Language")
  .set("CSS", "Cascading Style Sheets")
  .set("JS", "JavaScript");
```

:::

::: details `get()` - получить значение по ключу

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Получить значение по ключу
const a = map.get(42);
```

:::

::: details `size` - получить кол-во элементов

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Получить кол-во элементов
const a = map.size;
```

:::

::: details `has()` - проверка наличия значения по ключу

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Проверка наличия значения по ключу
const a = map.has(42);
```

:::

::: details `delete()` - удалить значение по ключу

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Удалить значение по ключу
map.delete(42);
```

:::

::: details `clear()` - очистка map

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Очистка map
map.clear();
```

:::

::: details `keys()` - возвращает перебираемый объект с ключами

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Возвращает перебираемый объект с ключами
const a = map.keys();
```

---

```js
// Обратно получаем не массив, а объект MapIterator (объект для перебора)
console.log(map.keys()); // MapIterator {"HTML", "CSS", "JS"}

// Получить объекты по порядку можно используя оператор распространения
console.log(...map.keys()); // HTML CSS JS

// Можно получить массив обернув в []
console.log([...map.keys()]); // ["HTML", "CSS", "JS"]
```

:::

::: details `values()` - возвращает перебираемый объект со значениями

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Возвращает перебираемый объект со значениями
const a = map.values();
```

---

```js
console.log([...map.values()]); // ["HyperText Markup Language", "Cascading Style Sheets", "JavaScript"]
```

:::

::: details `entries()` - возвращает перебираемый объект с парами [ключ, значение]

- Объект MapIterator, пары идут в порядке добавления. Массив массивов получится только после преобразования: `[...map.entries()]` или `Array.from(map.entries())`

```js
const map = new Map();
map.set(42, "Ответ на главный вопрос");
// Возвращает перебираемый объект с парами [ключ, значение]
const a = map.entries(); // MapIterator {42 => "Ответ на главный вопрос"}
```

---

```js
console.log([...map.entries()]); // Массив массивов
// Можно использовать для клонирования map
const map2 = new Map(map.entries());

// Получить ключ:значение с помощью деструктуризации
const [first, second, third] = map;
console.log(first); // ["HTML", "HyperText Markup Language"]
console.log(second); // ["CSS", "Cascading Style Sheets"]
console.log(third); // ["JS", "JavaScript"]

const [[key, value], second, third] = map;
console.log(key); // HTML
console.log(value); // HyperText Markup Language
```

:::
