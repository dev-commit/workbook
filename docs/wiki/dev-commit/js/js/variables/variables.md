# `var`, `let`, `const`

## Информация

- Глобальная переменная относится к глобальному объекту `window`
- Переменная без var попадает в глобальную область видимости

## Сравнение

### `var`

1. Функциональная область видимости
2. Переменная видна до объявления

```js
console.log(a); // undefined
var a = 77;
```

- _Инициализируются_ значением _undefined_ прямо когда создается связывание в начале _scope_

### `const`

1. Могут быть присвоены только в части инициализатора определения
2. Не может менять ссылку

```js
const one = 1;
```

3. Изменение элементов объектов и массивов

```js
const user = {
  name: "Tony",
};
user.name = "Jack"; // Допустимо
user = 5; // Ошибка
```

### `let` и `const`

1. Блочная область видимости
2. Переменная видна только после объявления

```js
console.log(a); // ReferenceError: a is not defined
let a = 77;
```

- _Остаются неинициализированными_
- _Инициализируются_ только в момент выполнения выражений let/const/class, все перед этим (выше) - _Temporal Dead Zone_

::: tip

- **Temporal Dead Zone** (временная мертвая зона) - время между созданием переменной scope и инициализацией
  :::

3. **Нельзя повторно объявлять**

```js
let x;
let x; // SyntaxError: Identifier 'x' has already been declared
```

4. **При использовании в цикле, для каждой итерации создаётся своя переменная**

```js
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i)); // 0, 1, 2
}
```

## Примеры

::: details Пример на цикл и замыкание

```js
for (var i = 0; i < 5; i++) {
  setTimeout(() => {
    console.log(i);
  }, 10);
}
// 5, 5, 5, 5, 5

// Каждый раз создается новая переменная
for (let i = 0; i < 5; i++) {
  setTimeout(() => {
    console.log(i);
  }, 10);
}
// 0, 1, 2, 3, 4
```

:::
