# Оператор объединения с null '??'

## Теория

::: info

- https://learn.javascript.ru/nullish-coalescing-operator - Learn JavaScript

:::

- Выражение «определено», если оно отличается от _null_ или _undefined_
- Оператор `??` позволяет выбрать первое «определённое» значение из списка, если оно НЕ _null/undefined_
- Используется для присвоения переменным значений по умолчанию

**Результат выражения `a ?? b` будет следующим:**

- `a`, если значение `a` определено
- `b`, если значение `a` не определено

## Варианты

### Сравнение с `||`

- `||` - возвращает первое истинное значение
- `??` - возвращает первое определённое значение

### Ложные значения

- Оператор _||_ не различает _false_, _0_, _пустую строку_, _null/undefined_. Для него они все одинаковые, т.е. являются ложными значениями. Если первым аргументом для оператора _||_ будет любое из перечисленных значений, то в качестве результата получим второй аргумент
- Однако на практике часто требуется использовать значение по умолчанию только тогда, когда переменная является _null/undefined_

```js
const height = 0;

console.log(height || 100); // 100
console.log(height ?? 100); // 0
```

### Приоритет

- Оператор `??` имеет довольно низкий приоритет: _5_, согласно [таблице на MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#table)
- Оператор `??` вычисляется до `=` и `?`, но после большинства других операций, таких как `+`, `*`
- Из этого следует, что если нужно выбрать значение при помощи оператора `??` вместе с другими операторами в выражении, следует добавить круглые скобки

```js
const height = null;
const width = null;

// Важно: используйте круглые скобки
const area = (height ?? 100) * (width ?? 50);

console.log(area); // 5000
```

- Иначе, если опустить скобки, то оператор `*` выполнится первым, так как у него приоритет выше, чем у `??`, а это приведёт к неправильным результатам

<!-- prettier-ignore -->
```js
// Без круглых скобок
const area = height ?? 100 * width ?? 50;

// ...то же самое, что предыдущее выражение (вероятно, это не то, что нам нужно):
const area = height ?? (100 * width) ?? 50;
```

## Использование `??` вместе с `&&` или `||`

- По соображениям безопасности JavaScript запрещает использование оператора _??_ вместе с _&&_ и _||_, если только приоритет явно не указан в круглых скобках

```js
const x = 1 && 2 ?? 3; // Синтаксическая ошибка
const x = (1 && 2) ?? 3; // Работает без ошибок
console.log(x); // 2
```

## Примеры

### Пример #1

```js
// Будет height=100, если переменная height равна null или undefined
const height = height ?? 100;
```

### Пример #2

```js
// Через ??
const result = a ?? b;
// Через тернарный оператор
const result = a !== null && a !== undefined ? a : b;
```

### Пример #3

- Можно записать последовательность из операторов _??_, чтобы получить первое значение из списка, которое не является _null/undefined_

```js
const firstName = null;
const lastName = null;
const nickName = "Суперкодер";

// Показывает первое определённое значение

// Через ??
console.log(firstName ?? lastName ?? nickName ?? "Аноним"); // Суперкодер
// Через ||
console.log(firstName || lastName || nickName || "Аноним"); // Суперкодер
```
