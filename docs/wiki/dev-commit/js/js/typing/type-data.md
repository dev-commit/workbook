# Типы данных

## 8 типов данных

**Примитивы**

1. `Number` - Число 64-битный float
2. `String` - Строка
3. `Boolean` - Булевый, логический
4. `null` - Специальное пустое или неизвестное значение (присваивается самостоятельно)
5. `undefined` - Специальное неприсвоеное значение (возвращается из JS)
6. `Symbol` - Символ (ES6)
7. `BigInt` - Целые числа больше 253BigInt(значение)

**Объекты**

8. `Object` - Array, Function, Object

## null и undefined

::: tip
**undefined** («неопределенный») - представляет собой значение по умолчанию:

- переменной, которой не было присвоено значения, т.е. объявленной, но не инициализированной переменной
- функции, которая ничего не возвращает явно, например, console.log(1)
- несуществующего свойства объекта

:::

::: tip
**null** («значение отсутствия значения») - значение, которое присваивается переменной явно
:::

## Информация

- _Назначение типов данных_: хранить разного рода информацию
- _Примитивам_ нельзя назначать методы (при считывании будет undefined), но считывать их можно
- Специальные числовые значения `Infinity` и `NaN`
