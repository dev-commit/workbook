# Сравнение типов

## Сравнение

Вычисление по короткой схеме в булевых операциях

```js
// && - первое значение
// || - последнее значение

false && ''         // false
false || ''         // ''
'' || 'Yes'         // 'Yes'
{} && 'Some'        // 'Some'
{} || 'Some'        // Object {}
{a: 10} && 'Some'   // 'Some'
{a: 10} || 'Some'   // Object { a: 10}
{} && []            // []
0 || true           // true
null || 0           // 0
undefined && 0      // undefined
'' || 0 && true     // 0
{} || 0 && true     // Object {}
false || {} && true // true
```

```js
0 / '' / null / undefined                               // => false
77 / -1 / 'Hello' / {} / [] / function() {} / Symbol()  // => true
```

### Числа и строки

- При сравнении значений разных типов, используется числовое преобразование. Оно применяется к обоим значениям

```js
'2' > 1           // true   - сравнивается как 2 > 1
'01' == 1         // true   - сравнивается как 1 == 1
9 + "1"           // "91"   - строка сильнее
91 - "1"          // 90     - вычитать только числа
'1' + 1           // "11"
'b' + 'a' + +'a'  // 'baNaN'
```

### Массивы и объекты

```js
[1] + 1      // "11"
[1, 2] + 5   // "1,25"
[] + []      // ""                 - складывать можно строки и цифры, приводим к строкам, т.к. сильнее
[] + {}      // "[object Object]"  - [] к строке, {} - объект [obj Obj]
{} + []      // 0                  - false + false = 0
[] == 0      // true               - false == false
[4] === ![4] // false
[4] === [4]  // false
```

```js
(!+[]+[]+![]).length // 9
	!+[] == true
	[]   == ""
	![]  == false
	"truefalse".length == 9
```

### Булево значение

```js
false == 0          // true  - false становится числом 0
true == 1           // true  - true становится числом 1
true + true + true  // 3     - true == 1
true - true         // 0     - true == 1
```

### null и undefined

- Значения null и undefined равны == друг другу и не равны чему бы то ни было ещё
- При преобразовании в число null становится 0, а undefined становится NaN

```js
undefined == undefined  // true
null == null            // true
undefined == null       // true
```

### Функции

- Функция - «объект первого класса». Функция - это значение такое же, как число, строка или объект. Мы можем записать функцию в переменную, можем положить её в массив или в свойство объекта. Мы даже можем сложить две функции

```js
function hello() {};
function world() {};
console.log(hello + world); // => "function hello() {}function world() {}"
```

### Дробные числа

```js
0.5 + 0.1 == 0.6     // true
0.1 + 0.2 == 0.3     // false   - неточность перевода в двоичную систему
```

### Строки

- Cравниваются численные коды символов Unicode

```js
'Б' > 'А'          // true
'а' > 'Я'          // true, строчные буквы больше прописных
'Банан' > 'Анна'   // true, если первая буква первой строки больше – значит первая строка больше, независимо от остальных символов
'Привет' > 'Прив'  // true, любая буква больше отсутствия буквы
```
