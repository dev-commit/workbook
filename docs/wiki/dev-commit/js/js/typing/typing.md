# Типизация

### Языки программирования:

- I. Типизированные
- II. Нетипизированные (бестиповые) [Ассемблер, Forth и Brainfuck]

### Виды типизации

- **Статическая типизация** - тип задается при определении переменной, нельзя положить переменную другого типа. Конечные типы переменных и функций устанавливаются на этапе компиляции (компилятор точно знает, какой тип где находится) [C, Java, C#]
- **Динамическая типизация** - тип не задается. Все типы выясняются уже во время выполнения программы. Возможна запись в переменную значения другого типа [Python, JavaScript, Ruby]
- **Сильная типизация (строгая)** - язык не позволяет смешивать в выражениях различные типы и не выполняет автоматические неявные преобразования, например нельзя вычесть из строки множество [Java, Python, Haskell, Lisp]
- **Слабая типизация (нестрогая)** - неявное приведение типов. Н-р: операции сложения с разными типами данных. Автоматически выполняется множество неявных преобразований, даже если может произойти потеря точности или преобразование неоднозначно [C, JavaScript, Visual Basic, PHP]
- **Явная типизация** - тип новых переменных / функций / их аргументов нужно задавать явно [C++, D, C#]
- **Неявная типизация** - перекладывают эту задачу на компилятор / интерпретатор [PHP, Lua, JavaScript]

### Примеры типизации

1. Статическая [C, Java,C#]
2. Динамическая [JavaScript, PHP, Python, Ruby]
3. Строгая (сильная) [Java, Python, Haskell, Lisp]
4. Нестрогая (слабая) [PHP, JavaScript, Visual Basic]
5. Явная [C++, D, C#]
6. Неявная [JavaScript, PHP, Lua]
