# Символы

## Цифры

› "23"

```bash
🟢/[\d]/# все цифры в диапазоне 0-9
🟠/[\D]/# символы кроме цифр в диапазоне 0-9
🟢/[0-4]/# цифры в диапазоне 0-4
🟠/[^0-4]/# символы кроме цифр в диапазоне 0-4
```

## Символы

› "Hello, Tony!"

```bash
🟢/[\s]/# пустые символы (пробелы, табуляция, перенос строк)
🟢/[\S]/# все не пустые символы
🟢/[,]/# символ запятая ","
🟠/[.]/# символ точка "."
🟢/[\w]/# символы, являющиеся буквами или цифрами
🟢/[\W]/# символы, НЕ являющиеся буквами или цифрами
```

```bash
🟢/./# любой символ кроме переноса строк
🟠/\./# символ "." (экранирование)
🟠/[.]/# символ "." (символьный класс)
```

## Буквы

› "Привет. You have 23 likes"

```bash
🟢/[a-zA-Z]/# любая EN буква в любом регистре
🟢/[а-яА-Я]/# любая RU буква в любом регистре
```

## Комбинации

› "Привет. You have 23 likes"

```bash
🟢/[a-zA-Zа-яА-Я]/# любая RU / EN буква
🟢/[a-zA-Z]/g# любая EN буква - глобальный поиск
🟢/[a-zA-Z.,]/# любая EN буква / символ "," / символ "."
🟢/[a-zA-Zа-яА-Я.,-\d\s]/# любая EN/RU буква, символы '.,-', цифры 0-9, пустые символы
```
