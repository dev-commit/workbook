# Поиск по словам

› "О дивный новый Мир"

```bash
🟠/^новый/# поиск с начала строки
🟢/^О дивный/# поиск с начала строки
🟠/О дивный$/# поиск с конца строки
🟢/Мир$/# поиск с конца строки
🟢/^О дивный новый Мир$/# точное совпадение: начало и окончание
🟠/[^(^О дивный новый Мир$)]/# точное совпадение (отрицание)
```

```bash
🟢/новый(?= Мир)/# слово "новый" после которого ЕСТЬ пробел и слово "Мир"
🟠/новый(?! Мир)/# слово "новый" после которого НЕТ пробела и слова "Мир"
```

› "hello"

- Кол-во любых символов между буквами "h" и "o"

```bash
🟢/h.{3}o/# 3 символа
🟠/h.{4,7}o/# диапазон 4-7 символов
🟢/h.{2,}o/# от 2 и более символов
🟢/h.+o/# от 1 и более символов
🟢/h.*o/# 0 и более символов
```
