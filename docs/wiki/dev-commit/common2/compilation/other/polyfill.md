# Полифиллы

- **«Полифилл» (англ. polyfill)** - библиотека, которая добавляет в старые браузеры поддержку возможностей, которые в современных браузерах являются встроенными

1. Проверка, есть ли встроенная возможность. Если свойство или метод поддерживается, то его значение не может быть undefined
2. Эмуляция, если её нет: запись в прототип
