# Программная навигация

## Информация

- Внутри экземпляра Vue у вас есть доступ к экземпляру маршрутизатора через `$router`. Поэтому можно вызвать `this.$router.push`

## Методы

- _`router.push(location, onComplete?, onAbort?)`_ (аналог: _window.history.pushState_) - для перехода к новому URL. Метод добавляет новую запись в историю навигации, что позволяет клику пользователя по кнопке "назад" в браузере сработать привычным образом. В качестве аргумента можно передать строку или объект, описывающий маршрут
- _`router.replace(location, onComplete?, onAbort?)`_ (аналог: _window.history.replaceState_) - действует как router.push, с той лишь разницей, что переход осуществляется без добавления новой записи в историю навигации, а заменяет текущую запись в нём
- _`router.go(n)`_ (аналог: _window.history.go_) - метод принимает параметром целое число, которое указывает на сколько шагов необходимо перейти по истории навигации

## Код

### `router.push`

```bash
<router-link :to="...">	# Декларативная запись
router.push(...)        # Программная запись
```

```js
// Строка
router.push("home");

// Объект
router.push({ path: "home" });

// Именованный маршрут
router.push({ name: "user", params: { userId: "123" } });

// Со строкой запроса, получится /register?plan=private
router.push({ path: "register", query: { plan: "private" } });
```

### `router.replace`

```bash
<router-link :to="..." replace> # Декларативная запись
router.replace(...)             # Программная запись
```

### `router.go`

```js
// Перейти на одну запись вперёд, эквивалентно history.forward()
router.go(1);

// Перейти на одну запись назад, эквивалентно history.back()
router.go(-1);

// Перейти на 3 записи вперёд
router.go(3);

// Если записей в истории недостаточно много, переход просто не произойдёт
router.go(-100);
router.go(100);
```
