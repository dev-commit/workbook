# Basis

```python
print()                  # Вывод в консоль
print("Привет \"Мир")    # Экранирование кавычек
print('Привет \nМир')    # Перевод строки
print("""Привет
Мир""")                  # Многострочный вывод

a = input('Ваше имя: ')  # Запрос данных у пользователя (возвращает строку)

print('Привет' * 3)      # Умножение строк
print(3 * 'Привет')      # Умножение строк

# Лексикографическое сравнение.
# Сравнение строк, у какой строки больший вес.
# Регистр строк учитывается (сравниваются коды символов)
print('Test' > 'Tesa')

del test                 # Удаление переменной test
```

- Метасинтаксические переменные - имена-заглушки, которые по соглашению используют в примерах (не зарезервированы языком)

```python
foo
bar
```

```python
# In-place операторы (изменяют значение переменной на месте)
a += 10
a += 1  # Инкрементирование
```

```python
a1 = 5 ** 2   # Возведение в степень (2)
a2 = 20 // 6  # Частное (сколько 6 в числе 20)
a3 = 20 % 6   # Деление по модулю
```
