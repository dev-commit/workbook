# Конструкция if-else

```php
$weather = 'хорошая';
if($weather == 'хорошая') {
	echo('Идём гулять');
} else {
	echo('Идём в кино');
}
```

## Двойные условия

```php
$a = "Дождь";
$b = "Хорошее";
if ($a == "Солнце" || $b == "Хорошее") {
    echo "Идём гулять";
}
else {
    echo "Идём в кино";
}
```
