# Функции PHP

## Информация

- `empty($a)` - пустая ли переменная
- `isset($a)` - существует ли переменная
- `is_dir($dir)` - существует ли директория
- `mkdir($dir, 0777)` - создать директорию
- `date('Y-m-d')` - дата
- `date('H:i')` - время
- `rand(1, 1000)` - любое число в диапазоне от 1 до 1000
- `unset($a)` - удаление переменной `$a`
- `exit()` - окончание работы скрипта
- `include('func.php')` - подключение скрипта (если файла нет - предупреждение)
- `require('func.php')` - подключение скрипта (если файла нет - фатальная ошибка)
- `mb_strtolower($name, 'UTF-8')` - перевод в нижний регистр
- `file_get_contents('../include/header.html')` - получить содержимое html файла
- `var_dump($arr)` - дамп информации о переменной
