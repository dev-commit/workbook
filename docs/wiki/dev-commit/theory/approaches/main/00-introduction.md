# Подходы и паттерны (краткий обзор)

Этот раздел — “выжимка” общеизвестных паттернов и инженерных подходов, которые **используются в платформе и описаны в документации**. Цель — иметь короткие, самодостаточные заметки, которые можно изучать отдельно от конкретной кодовой базы.

## Простой пример

Как этим пользоваться: выбираете подход → читаете страницу → запускаете пример в песочнице.

```ts
// мини-эксперимент: "подмена" зависимости
type Random = { next: () => number };
const prodRandom: Random = { next: () => Math.random() };
const testRandom: Random = { next: () => 0.42 };

function pickPrize(r: Random) {
  return r.next() > 0.5 ? "gold" : "silver";
}

console.log(pickPrize(prodRandom));
console.log(pickPrize(testRandom)); // детерминированно
```
