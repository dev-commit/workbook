## Цель

- Способствуют созданию системы, которую будет легко поддерживать и расширять в течение долгого времени
- Способствуют легкому понимают кода и его переиспользованию

## Когда следует применять

- _Жесткость_ - трудно вносить изменнея в код. Одно изменение вносит изменение в другие модули
- _Хрупкость_ - свойство программы повреждаться во многих местах при внесении одного изменения
- _Ненужная сложность_ - содержание элементов не используемых в данный момент
- _Ненужные повторения_ - проблема дублирования кода
- _Непрозрачность_ - трудность кода для понимания
