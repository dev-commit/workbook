# Хэширование (Hashing algorithm)

## Информация

::: tip Хэширование

- **Хэширование** - функция, в которой что-то передается, н-р строка. Функция превращает эту строку в hash-код и по этому hash-коду можно сделать поиск
- Используется для Hash Table, где в качестве ключа используется hash-код
- Алгоритм хэширования MD5

:::
