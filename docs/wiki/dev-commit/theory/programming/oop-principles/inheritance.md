# Наследование

## Информация

::: tip Наследование

- **Наследование** - описание нового класса на основе уже существующего с частично или полностью заимствующейся функциональностью
  :::

- Наследование транзитивно: класс может наследоваться от другого класса, который наследуется от третьего, и так далее вплоть до базового класса (Object). Наследник может переопределить какие-то методы и поля чтобы изменить поведение по умолчанию
- _SuperClass_: базовый, родительский, предок, надкласс, супер класс
- _SubClass_: наследник, дочерний, потомок, подкласс, суб класс, производный
- Подкласс должен являться более специализированной версией супер-класса

::: tip Множественное наследование

- **Множественное наследование** - у одного подкласса существует сразу несколько супер-классов
  :::

## Использование

**Использовать**

- Класс-потомок использует большинство свойств и методов базового класса
- С классом-потомком удобно работать по принципам SOLID

**Не использовать**

- Реализация класса-потомка сильно отличается от наследуемого класса
- Приходится переопределять методы и свойства у класса-потомка (что некорректно по SOLID)
- Класс-потомок не использует методы и свойства из базового класса или их использование крайне мало
