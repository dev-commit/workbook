# UDP

- **UDP** (User Datagram Protocol) - протокол пользовательских датаграмм
- В отличие от TCP - более простой протокол не заинтересованный в целостоности передаваемого сообщения
- UDP лучше для видеоконференций (чем TCP), т.к. часть данных может не дойти и это не критично в рамках потока видео
