# Информация

::: info
https://nodejs.org/en/
:::
- **Node.js** - платформа, среда запуска JS на локальном компьютере
- При установке Node.js, устанавливается NPM

```bash
node -v      # Проверка версии Node.js
node index   # Запуск файла из текущей директории
npm init -y  # Инициализация package.json
```
