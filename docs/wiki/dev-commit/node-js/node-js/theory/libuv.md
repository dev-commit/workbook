# libuv

## Информация

::: info

- https://libuv.org/

:::

::: tip Определение

- **libuv** - многоплатформенная библиотека C, которая обеспечивает поддержку асинхронного ввода-вывода на основе Event Loops. Она поддерживает epoll, kqueue, Windows IOCP и порты событий Solaris. Она в первую очередь предназначена для использования в Node.js, но также используется в других программных проектах

:::

- libuv - приносит абстракцию над системным _Демультиплексором_. Т.к. в каждой системе свой Демультиплексор (Linux, Windows и т.д.)
