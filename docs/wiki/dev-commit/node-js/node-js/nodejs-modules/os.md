# `os`

## Информация

::: tip Определение

- **os** - информация о текущей операционной системе

:::

```js
const os = require("os");
```

## Методы

- `os.platform()` - Название ОС
- `os.arch()` - Архитектура процессора (н-р: x64)
- `os.cpus()` - Информация по процессорам
- `os.freemem()` - Свободная память
- `os.totalmem()` - Всего памяти
- `os.homedir()` - Домашняя директория
- `os.uptime()` - Сколько времени включена система
