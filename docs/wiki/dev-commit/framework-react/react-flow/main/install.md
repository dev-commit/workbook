# Установка и настройка

::: warning

- В React Flow v12 пакет `reactflow` переименован в `@xyflow/react`:
  - установка - `npm i @xyflow/react`
  - компонент `ReactFlow` импортируется по имени: `import { ReactFlow } from "@xyflow/react"`
  - стили - `@xyflow/react/dist/style.css` вместо `reactflow/dist/style.css`

:::

## Vite template

::: info

- https://reactflow.dev/learn#vite-template - Vite template

:::

```bash
npx degit xyflow/vite-react-flow-template app-name
```

## Installation

::: info

- https://reactflow.dev/learn#installation - Installation

:::

```bash
npm create vite@latest app-name -- --template react
npm i reactflow
```
