# React.Component.constructor()

::: danger

**`constructor(props)`** - вызывается при создании компонента

> - `props` - props

:::

- Вы можете _не использовать_ конструктор в React-компоненте, если вы не определяете состояние или не привязываете методы

**Обычно используют для двух целей:**

- Инициализация внутреннего состояния через присвоение объекта `this.state`
- Привязка обработчиков событий к экземпляру
