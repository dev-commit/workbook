# getDerivedStateFromProps()

::: danger

**`static getDerivedStateFromProps(props, state)`** - вызывается непосредственно перед вызовом метода render, как при начальном монтировании, так и при последующих обновлениях

> - `props` - props
> - `state` - state

:::

- Он должен вернуть объект для обновления состояния или null, чтобы ничего не обновлять
- Существует для редких случаев, когда состояние зависит от изменений в пропсах. Например, это подойдёт для реализации компонента `<Transition>`, который сравнивает свои предыдущие и следующие дочерние компоненты, чтобы решить, какой из них нужно анимировать. Метод запускается при каждом рендере, независимо от причины
