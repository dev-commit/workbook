# v-iframe

## Props

- `src="https://codepen.io/…"` - адрес встраиваемой страницы
- `height="550"` - высота (по умолчанию 400)

## Варианты

### CodePen

```vue
<v-iframe height="550" src="https://codepen.io/LetsCode-Dev/embed/NWvOaaz" />
```
