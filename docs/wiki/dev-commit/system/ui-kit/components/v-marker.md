# v-marker

## Props

- `marker="+"` - маркер перед текстом: `+` - ✅, `-` - 🅾️, `*` - ⭐️

## Варианты

### Маркеры

```vue
<v-marker marker="+">Плюс</v-marker>
<v-marker marker="-">Минус</v-marker>
<v-marker marker="*">Звездочка</v-marker>
```

- <v-marker marker="+">Плюс</v-marker>
- <v-marker marker="-">Минус</v-marker>
- <v-marker marker="*">Звездочка</v-marker>
