# Порядок слов в вопросе

### 1. Вопросительное слово (не обязательно)

- Where / When / What / etc.

### 2. Вопросительная фраза (не обязательно)

- Уточнение, н-р: kind of coffee

### 3. Вспомогательный глагол

- Пример для Present Simple

- Do / Does - Глагол (если есть действие)
- Am / Is / Are - To Be (если нет действия / глагола)

### 4. Подлежащее

- I / You / We / They
- He / She / It

### 5. Сказуемое

- Любой глагол: like / have / live etc.

---
- What kind of coffee do you like?

```bash
1. What           # Вопросительное слово
2. kind of coffee # Вопросительная фраза (уточнение)
3. do             # Вспомогательный глагол
4. you            # Подлежащее
5. like           # Сказуемое
```
