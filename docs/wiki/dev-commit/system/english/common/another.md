# Another / Other

| - Another - ед. ч. - Другой (один, неопределенный) | - Is this your cat? - No, it's another cat |
| --- | --- |
| - Other - мн. ч. - Другие (множественное число, неопределенные) | - Are these your cats? - No, these are other cats |
| - Others - Другие (когда не говорим, кто именно, без существительного, неопределенные) | - Are these your cats? - No, these are others |
| - The other - Тот другой, те другие (конкретный) | - That cat is cute. The other cat is so aggressive - I've talked to Josh and Sarah, but I haven't talked to the other students yet |
| - The others - Те другие, конкретные. Когда опущено существительное | - I loved only her, but I liked all the others - I've talked to Josh and Sarah, but I haven't talked to the others yet |
