# Местоположение

## There is / There arePresent Simple

- There is (there's) - там (ед.ч.)
- There are - там (мн.ч.)

|  | Singular | Plural |
| --- | --- | --- |
| + | There's a piano | There are some pictures |
| - | There isn't a piano | There aren't any pictures |
| ? | Is there a piano? | Are there any pictures? |
| Yes / No | Yes, there is. No, there isn't | Yes, there are. No, there aren’t |

### "There is" vs "It is" и "There are" vs "They are"

| There is / There are (Описываем где находится) | It is / They are (Описываем какой предмет) |
| --- | --- |
| There is a garden in the yard | It is a beautiful garden |
| There are a lot of rooms in the flat | They are huge |

## There was / There werePast Simple

- Аналогичен There is / There are
- there is (there’s) / there are - там

|  | Singular | Plural |
| --- | --- | --- |
| + | There was a piano | There were only three guests |
| - | There wasn't a piano | There weren't any more people |
| ? | Was there a piano? | Were there any lights? |
| Yes / No | Yes, there was. No, there wasn’t | Yes, there were. No, there weren't |
