# GitHub Packages

::: info

- https://docs.github.com/en/packages - Документация
  :::

::: tip GitHub Packages

- **GitHub Packages** - это реестр пакетов, встроенный в GitHub. Можно хранить и раздавать пакеты рядом с репозиторием, управлять доступом через GitHub (org/team permissions), и использовать токены GitHub для публикации/установки.

:::
