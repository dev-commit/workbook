# Vite Library Mode

## Информация

::: tip Vite Library Mode

- **Vite Library Mode** — это режим сборки, в котором Vite использует Rollup для сборки не приложения, а переиспользуемой библиотеки (npm‑пакета).
  :::

- Vite не “изобретает” отдельный сборщик для библиотек — он просто настраивает Rollup под задачу публикации пакета. Поэтому большая часть тонких находится живёт в `build.*` и `build.rollupOptions.*`.

## Отличия от обычного приложения

- **Есть явный entrypoint библиотеки** (`build.lib.entry`)
- **Фокус на форматах для публикации**: обычно ESM
- **Зависимости приложения не должны “запекаться” внутрь**: React, ReactDOM выносятся во внешние зависимости (через `rollupOptions.external`) и описываются как `peerDependencies`
- **Output — набор артефактов в `dist/`**, которые потом указываются в `package.json` через `exports`/`types`
