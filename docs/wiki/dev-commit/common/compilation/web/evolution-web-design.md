# Эволюция веб-дизайна

## Информация

- **1990 - 2000** - Нет дизайна
- **2000 - 2010** - Скевоморфизм
- **2010 - 2013** - Flat Design
- **2014 - 2017** - Material Design (Google)
- **2017 - ...** - Fluent Design (Microsoft)
- **2019 - 2020** - Неоморфизм (Neumorphism, «новый скевоморфизм»): мягкие объёмные элементы, выдавленные из фона
- **2020 - 2021** - Глассморфизм (Glassmorphism): полупрозрачные слои с размытием фона (macOS Big Sur, Windows 11)
- **2021 - ...** - Material You (Material Design 3, Google): цвета интерфейса подстраиваются под обои
- **2022 - ...** - Необрутализм (Neubrutalism): толстые рамки, жёсткие тени, контрастные цвета
- **2025 - ...** - Liquid Glass (Apple): стекло с преломлением и бликами (iOS 26, macOS Tahoe 26)
