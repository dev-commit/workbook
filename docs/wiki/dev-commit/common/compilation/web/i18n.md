# i18n | L10n | a11y

- i18n - Internationalization (Интернационализация)
- L10n - Localization (Локализация)
- a11y - Accessibility (Доступность)

- **Интернационализация** - адаптация продукта для потенциального использования практически в любом месте, в то время как
- Интернационализация производится на начальных этапах разработки
- **Локализация** - добавление специальных функций для использования в некотором определённом регионе
- Локализация производится для каждого целевого языка
