# Информация

## Информация

::: tip Определение

- **TypeScript** - язык программирования, который является надмножеством JavaScript, имеет статическую систему типов и собственный компилятор. Статическая типизация позволяет отлавливать ошибки и баги во время компиляции, ещё до запуска приложения

:::
