# Tuple

## Информация

::: tip Определение

- **Tuples (кортежи)** - так же, как и массивы, представляют набор элементов, для которых уже заранее известен тип. Массив из разных типов данных

:::

```ts
// Определение и инициализация кортежа
const contact: [string, number] = ["Tony", 23];
```

```ts
// Определение кортежа - кортеж состоит из двух элементов - строки и числа
let contact: [string, number];

// Инициализация кортежа
contact = ["Tony", 23];

// Использование кортежа
console.log(contact[1]); // 23
contact[1] = 25;
```
