# Any vs Unknown

## Unknown можно переопределить

- _unknown_ можно определить потом через _as_

```ts
const a: any = {};
const b: unknown = {};

a.b = 1; // Можно добавить ключи
b.a = 2; // Нельзя добавить ключи

(param as Custom).something;
```

## unknown - безопаснее, чем any

- При указании через _any_ есть риск обратиться к методу неверного типа. Н-р, предполагали, что будет string и обратились к свойству _length_, но получили undefined, т.к. там был объект.
- _unknown_ не даст сделать подобного - он будет выдавать ошибку
