# Декораторы

## Информация

::: tip Определение

- **Декораторы** - являются инструментом декларативного программирования, они позволяют добавить к классам и их членам метаданные и тем самым изменить их поведение без изменения их кода

:::

- Декораторы представляют собой функции
- Декораторы используют форму `@expression`, т.е. при использовании ставится символ `@` перед именем декоратора. Хотя по сути expression может быть любая функция. Эта функция будет вызвана в процессе выполнения программы, причем вызывающий код добавит аргументы с информацией о том объекте, который был задекорирован.
- Важно, что декоратор - это лишь функция. При использовании среда исполнения сначала вызовет функцию-декоратор, и только потом будет выполнен основной сценарий объекта (если код декоратора содержит этот вызов). При наличии нескольких декораторов у одного объявления их выражения вычисляются сверху вниз, а сами декораторы вызываются снизу вверх.
- Декоратор для функции, свойства или параметра функции можно применить только внутри некоего класса. В настоящее время компилятор TypeScript не позволит применить декоратор для функции, которая написана вне класса.

### К каким элементам можно добавить декораторы

- Классы
- Методы
- Методы доступа (Геттеры и Сеттеры)
- Свойства
- Параметры

## Установка и настройка

- Декораторы являются экспериментальной функциональностью языка TypeScript (на 2021 год), поэтому при компиляции следует указывать параметр _experimentalDecorators_ в файле _tsconfig.json_

```json
{
  "compilerOptions": {
    "module": "commonjs",
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "target": "es2017"
  }
}
```

::: warning

- С TypeScript 5.0 стандартные декораторы (ECMAScript) работают без флага. `experimentalDecorators` нужен для старой (экспериментальной) реализации, в том числе для декораторов параметров и `emitDecoratorMetadata`

:::
