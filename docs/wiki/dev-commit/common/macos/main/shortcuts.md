# Keyboard shortcuts

- - свернуть приложение
- - закрыть приложение
- - скрыть приложение
- - покажет все скрытые файлы в директории
- - снимок ВСЕГО экрана (сохраняется на рабочий стол)
- - снимок ЧАСТИ экрана (сохраняется на рабочий стол)
- - удалить файл
- - открыть / закрыть приложение в полноэкранном режиме
