# Информация

## Элементы

### 1. Continuous Integration - непрерывная интеграция

- Короткоживущие функциональные ветки, команда сливает их с основной веткой разработки по несколько раз в день, процессы сборки и тестирования полностью автоматизированы, результат имеем в пределах 10 минут; развертывание выполняется вручную
- _Залили в develop. Автоматически запустилась сборка и автотесты_

### 2. Continuous Delivery - непрерывная доставка

- Автоматизируется CI + весь процесс релиза ПО. Может состоять из нескольких этапов. Развертывание в продакшен выполняется вручную
- _Сборка развертывается автоматизированно_

### 3. Continuous Deployment - непрерывное развертывание

- CI + CD + полностью автоматизированное развертывание в продакшен
- _Включает предыдущие шаги. Разворачивание в Production_

### Software Deployment - развертывание ПО

- Всн действия, которые делают программную систему готовой к использованию
