# Деплой

## Деплой через gh-pages

- Библиотека gh-pages берет файлы из директории _build_ и деплоит в связанный репозиторий на GitHib. Если в удаленном репозитории уже есть ветка gh-pages, то деплой происходи в нее. Если ветки нет, то она создается

## Особенности Github Pages

::: info

- https://docs.github.com/ru/pages/setting-up-a-github-pages-site-with-jekyll/about-github-pages-and-jekyll - О страницах GitHub и Jekyll
  :::

По умолчанию GitHub Pages не обрабатывает файлы, начинающиеся с нижнего подчёркивания. В документации ("О страницах GitHub и Jekyll") предлагается три решения этой проблемы:

1. Не использовать файлы, начинающиеся с нижнего подчёркивания
2. Добавить файл _.nojekyll_ в корневую папку сайта
3. Использовать директиву _include_ в файле _\_config.yml_ чтобы Jekyll не игнорировал эти файлы

### Добавить файл .nojekyll в корневую папку сайта

- Если создать пустой файл .nojekyll, то он не зугружется в ветку "gh-pages" при запуске скрипта `npm run gh-pages`
- Для этого нужно поменять скрипт "gh-pages"

```js
{
  "scripts": {
    "gh-pages": "gh-pages -d build",  // Исходный
    "gh-pages": "gh-pages -d build -t true", // Новый
  },
}
```
