::: tip Chromatic
**Chromatic** - сервис от создателей Storybook (Chromatic Inc.), заточенный под **дизайн-системы и UI в репозитории**.

:::

- Когда выбирать: Нужны *PR-превью Storybook + визуальные тесты* из коробки, минимум своей инфраструктуры.

## Функционал

- **Публикация Storybook** в облаке: по каждому PR или коммиту появляется ссылка на превью (как «живой» Storybook в браузере).
- **Визуальное регрессионное тестирование**: снимки экранов сторис, сравнение с базовой веткой, одобрение/отклонение изменений в UI.
- **Интеграция с GitHub/GitLab/Bitbucket**: статусы в PR, комментарии с диффами.
- Удобно для команд: ревью UI без локального `storybook dev`.

## Минусы / нюансы

- Платный после бесплатного лимита (снимки, билды, пользователи — по их тарифам).
- Это не «ваш хостинг продукта», а *инфраструктура вокруг Storybook* (превью + визуальные тесты).
