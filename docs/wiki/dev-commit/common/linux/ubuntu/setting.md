# Настройки

```bash
Menu -> Settings -> Region & Language
	-> Добавить русский язык
```

```bash
Menu -> Settings -> Language Support 
	-> Install (пакет для языков)
	-> Install / Remove Language -> Русский (выбрать)
	-> Перетащить "Русский" наверх
	-> Apply System-Wide
	-> Close
	-> Перезагрузка
```

```bash
Меню -> Обновления -> Настройки
	-> Программное обеспечение Ubuntu -> Загрузить с "Сервер Российская Федерация" -> Выбрать лучший сервер
	-> Другое ПО -> Партнеры Canonical
	-> Обновления -> Автоматически проверять наличие обновлений
```

```bash
Обзор -> Настройки -> Дополнительные настройки -> Расширения
	-> Ubuntu appindicators (check)
	-> Ubuntu dock (check)
```
