## Команды

- `sudo` - утилита, предоставляющая привилегии root для выполнения административных операций в соответствии со своими настройками
- `-r` - опция рекурсивного удаления

```bash
rmdir НазваниеДиректории # Удаление пустой директории
rm НазваниеФайла         # Удаление файла
rm -R НазваниеДиректории # Удаление директории с файлами
```

```bash
wget АдресUrl                       # Скачивание
sudo apt-get install НазваниеПакета # Скачивание с репозитория и установка
sudo apt-get remove НазваниеПакета  # Удаление пакета
sudo dpkg -i НазваниеПакета         # Установка скачанного пакета с расширением .deb
sudo apt-get update                 # Обновление
```
