# `git tag`

## Информация

::: danger

**`git tag`** - создает метку

:::

::: info

- https://git-scm.com/book/ru/v2/Основы-Git-Работа-с-метками - Работа с метками

:::

::: tip Определение

- Git использует два основных типа тегов: легковесные и аннотированные
- **Легковесный тег** - это что-то очень похожее на ветку, которая не изменяется - просто указатель на определённый коммит
- **Аннотированные** - теги хранятся в базе данных Git как полноценные объекты. Они имеют контрольную сумму, содержат имя автора, его e-mail и дату создания, имеют комментарий и могут быть подписаны и проверены с помощью GNU Privacy Guard (GPG)

:::

```bash
git tag v1                              # Создание легковесного тега
git tag -a R2021.4 -m 'Release 2021.4'  # Создание аннотированного тега
```

## Алгоритм работы

### 1. Информация о метках

```bash
git tag          # Просмотр списка меток
git show v1.0.0  # Показать коммит, отмеченный меткой
```

### 2. Создание метки

```bash
npm version 1.0.0                   # Автоматически повышает версию и создаёт тег (сделать для первой версии релиза)
git tag v1.0.0 -a -m 'description'  # Создание аннотированной ссылки
git tag v1.0.0                      # Создание легковесной ссылки
git tag v1.0.0 HashCommit           # Создание легковесной ссылки по номеру коммита
```

### 3. Push метки

```bash
git push origin v1.0.0  # Запушить тег
git push origin --tags  # Запушить все теги
```

### 4. Удаление метки

```bash
git tag -d v1.0.0                  # Удалить тег из локального репозитория
git push origin :refs/tags/v1.0.0  # Обновление удаленного тега пустым значением, что приводит к его удалению
git push origin --delete v1.0.0    # Удалить тег из удалённого репозитория
```
