# `git revert`

## Информация

::: danger

**`git revert`** - полная противоположность git cherry-pick. Она создаёт "антикоммит" для указанного коммита, таким образом отменяя изменения, внесённые в нём

:::

## Использование

```bash
git revert HashCommit # Создает коммит, который отменяет указанный коммит
```
