# `git log`

## Информация

::: danger

**`git log`** - показывает выполненные операции (коммиты)

:::

## Использование

```bash
git log                  # Информация по коммитам
git log -p               # Подробная информация по коммитам
git log --oneline        # Посмотреть все коммиты
git log --pretty=oneline # История коммитов
```

- `q` для выхода из лога
