# `git blame`

## Информация

::: danger

**`git blame`** - информация об авторах изменений конкретного файла: кто и в каком коммите последним изменил каждую строку

:::

## Использование

```bash
git blame FileName              # Показать список авторов файла
git blame --date=short FileName # Укоротить дату
git blame -L 5,8 FileName       # Указать интересующие строки
```
