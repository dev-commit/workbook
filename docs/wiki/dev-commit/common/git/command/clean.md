Удалить файлы не относящиеся к репозиторию. Это могут быть результаты сборки проекта или файлы конфликтов слияний

```bash
git clean      #
git clean -f   # удаление untracked files
git clean -df  #
```
- -d - удаляет еще и директории
- -f - обязательная опция, без нее гит откажется что-либо удалять
