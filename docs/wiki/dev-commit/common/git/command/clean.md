# `git clean`

## Информация

::: danger

**`git clean`** - удалить файлы, не относящиеся к репозиторию. Это могут быть результаты сборки проекта или файлы конфликтов слияний

:::

## Использование

```bash
git clean      # Без -f ничего не удалит
git clean -f   # Удаление untracked files
git clean -df  # Удаление untracked files и директорий
```

- `-d` - удаляет еще и директории
- `-f` - обязательная опция, без нее гит откажется что-либо удалять
