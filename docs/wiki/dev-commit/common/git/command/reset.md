# `git reset`

## Информация

::: danger

**`git reset`** - отмена изменений. Изменяет указатель HEAD и, опционально, состояние индекса

:::

- Передвигает ветку на указанный коммит
- Сбросить коммиты до начального в ветке
- Убрать из индексации все файлы и директории, которые возможно уже были проиндексированы с помощью _git add_

## Использование

```bash
git reset HEAD~          # Отменить 1 коммит
git reset HEAD~1         # Отменить 1 коммит
git reset HEAD^          # Отменить 1 коммит
git reset HEAD^1         # Отменить 1 коммит
git reset HEAD~2         # Отменить 2 коммита
git reset HashCommit     # Откатиться к конкретному коммиту (хэш из "git log")
git reset HEAD FileName  # Если изменения были индексированы и нужно откатиться перед самим коммитом
```

## Виды reset

- Каждый вид _reset_ позволяет откатиться к указанному коммиту

```bash
git reset --soft HEAD~   # Мягкий: ОСТАВИТЬ изменения последующих коммитов
git reset --hard HEAD~   # Жёсткий: УДАЛИТЬ последующие коммиты вместе с изменениями
git reset --mixed HEAD~  # Смешанный: среднее между --soft и --hard (по умолчанию)
git reset --keep HEAD~   # Жёсткий с сохранением изменений
git reset --merge HEAD~  # Жёсткий для отмены неудачного merge
```

- `--soft` - только перемещает ветку на указанный коммит. "working directory" и "index" без изменений
- `--mixed` - перемещает ветку на указанный коммит, сбрасывает "index", но не трогает "working directory"
- `--hard` - сбрасывает "working directory" и "index" (состояние проекта переключается на указанный коммит)

| Команда         | working directory | index         | current branch |
| --------------- | ----------------- | ------------- | -------------- |
| `reset --soft`  | без изменений     | без изменений | изменяется     |
| `reset --mixed` | без изменений     | изменяется    | изменяется     |
| `reset --hard`  | изменяется        | изменяется    | изменяется     |
