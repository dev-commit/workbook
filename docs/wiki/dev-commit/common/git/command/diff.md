# `git diff`

## Информация

::: danger

**`git diff`** - разница между рабочей директорией и индексом. Вычисление разницы между любыми двумя Git деревьями

:::

## Использование

```bash
git diff                 # Показать изменения, которые ещё не добавлены в Индекс
git diff --staged        # Разница между индексом и последним коммитом (изменения, которые находятся в Индексе)
git diff --cached        # Посмотреть, что добавлено в stage
git diff master features # Разница между любыми двумя коммитами "master" и "features"
git difftool             # Запускает внешнюю утилиту сравнения для показа различий в двух деревьях
```
