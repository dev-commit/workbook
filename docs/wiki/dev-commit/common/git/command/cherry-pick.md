# `git cherry-pick`

## Информация

::: danger

**`git cherry-pick`** - используется для того, чтобы взять изменения, внесённые каким-либо коммитом, и попытаться применить их заново в виде нового коммита наверху текущей ветки. Это может оказаться полезным, чтобы забрать парочку коммитов из другой ветки без полного слияния с той веткой

:::

- Вызывается из ветки, в которую нужно добавить коммиты

## Использование

```bash
git cherry-pick HashCommit1 HashCommit2
```
