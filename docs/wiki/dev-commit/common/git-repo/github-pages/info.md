## Информация

#### Ветка

- По умолчанию GitHub Pages настроен на ветку gh-pages
- Ветку можно переключить вручную: Settings -> Pages -> Branch -> ...

#### Нейминг

- Если название репозитория совпадает с названием акканута "account-name" - это будет корневой репозиторий: https://github.com/account-name ➡️ https://account-name.github.io/
- Если репозиторий не корневой то через "/" добавится название репозитория: https://github.com/project-name ➡️ https://account-name.github.io/project-name
